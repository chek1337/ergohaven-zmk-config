# ergohaven-zmk-config

Конфигурация ZMK для клавиатуры Velvet v3 UI (раскладка `velvet_v3_ui_ruen`).

## Раскладка

![velvet_v3_ui_ruen](keymap-drawer/velvet_v3_ui_ruen.svg)

Изображение генерируется автоматически через [keymap-drawer](https://github.com/caksoylar/keymap-drawer)
при каждом пуше изменений в `config/*.keymap`. Конфиг рендера — `keymap_drawer.config.yaml`.
