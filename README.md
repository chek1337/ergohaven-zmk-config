# ergohaven-zmk-config

ZMK configuration for the Velvet v3 UI keyboard (`velvet_v3_ui_ruen` keymap).

## Keymap

![velvet_v3_ui_ruen](keymap-drawer/velvet_v3_ui_ruen.svg)

Rendered automatically with [keymap-drawer](https://github.com/caksoylar/keymap-drawer)
on every push that touches `config/*.keymap`. Render config lives in `keymap_drawer.config.yaml`.
